# Trade UI

Ao criar ou alterar UI:

1. Leia `C:/Users/User/design-systems/trade-ui/CLAUDE.md` (regras obrigatórias).
2. Leia `C:/Users/User/design-systems/trade-ui/docs/brand-book.md` e o `C:/Users/User/design-systems/trade-ui/docs/components/<Componente>.md` de cada componente que for usar.
3. Use `C:/Users/User/design-systems/trade-ui/tokens/tokens.css` (CSS vars) ou `C:/Users/User/design-systems/trade-ui/tokens/tailwind.preset.js`; nunca valores literais.
4. Reaproveite `C:/Users/User/design-systems/trade-ui/components/react/*`. Componente novo: prefixo `tu-`, só tokens semânticos, suporte a `data-theme="dark"`.
5. Antes de entregar: confira os dois temas, contraste ≥ 4.5:1 em texto, números com `tabular-nums` e variações com sinal + seta.

Para ver o sistema renderizado, abra `C:/Users/User/design-systems/trade-ui/preview/index.html` no navegador (botão de lua alterna o tema).
